# 每日成长 · iPhone 打卡 PWA

## 功能
- 工作日：运动30分钟、吉他30分钟、单片机120分钟、科研120分钟、背单词30分钟。
- 周末：运动30分钟为必做，其余任务自由加练（不计入必做完成率）。
- 每日任务拆分勾选、进度条、历史日历、累计完成天数、连续打卡天数。
- 打卡记录保存在本机 localStorage；支持 JSON 导出/导入，离线可用。

## 部署和安装
PWA 需要部署到 HTTPS 网址才能正常在 iPhone 添加到主屏幕并启用离线缓存。直接在 iPhone 文件 App 中打开 index.html 不能得到完整的 PWA 能力。

1. 将本文件夹所有文件保持目录结构，上传到支持 HTTPS 的静态托管平台（如 GitHub Pages、Netlify 或 Cloudflare Pages）。
2. 使用 iPhone Safari 打开部署后的网址。
3. 选择 Safari 分享按钮 > 添加到主屏幕 > 添加。
4. 从桌面图标打开。首次联网访问后通常可以离线打开。

## 注意
- 所有打卡数据留在当前浏览器/主屏幕应用的本地存储，不同入口可能不共享。请固定从主屏幕图标打开。
- 更换手机、清除网站数据或重新安装应用可能导致数据丢失；务必定期在“成长记录”导出备份。
- 这是静态网页版 PWA，不是 Apple App Store 原生安装包。尚未部署到公共网址。
